{% comment %} The single toast region. Server-side Django messages are rendered into it on load. Client-side ones arrive as a `ui-toast` window event, which an HTMX response can raise with `HX-Trigger: {"ui-toast": {"message": "Saved", "tone": "success"}}`. One aria-live region for the whole page: several would compete, and a screen reader would announce them out of order. {% endcomment %}
